## Vrai scan LLM — procédure VPS (jamais en CI)

1. `cd redteam && uv sync`, charger les vraies clés depuis `../.env`
2. `uv run python run_redteam.py --live` (générateur `investia` → vrai LLM via LiteLLM)
3. Lire `garak_runs/*.report.jsonl` + `*.hitlog.jsonl` : **les hits sont revus
   par un humain** (garak ne fail pas dessus), résumé consigné dans
   `docs/redteam-<date>.md`.
