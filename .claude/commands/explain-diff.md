Lis le diff git en cours (`git diff`, ou `git diff main...HEAD` sur une branche) et explique-le en français, pour quelqu'un qui découvre le sujet :

1. **Quoi** a changé (fichiers, grandes lignes).
2. **Pourquoi** (lien avec la spec ou la décision dans `docs/09-decisions.md` si pertinent).
3. **Comment vérifier** : les commandes exactes à lancer (ex. `uv run pytest -q`).
4. **Risques** : ⚠️ ce qui pourrait casser ailleurs, et où vérifier.

Cite fichier:ligne pour chaque point. Ne modifie aucun fichier.
